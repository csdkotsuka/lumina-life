# LUMINA（ルミナ）サロン 公式Webサイト

プライベートエステサロン「LUMINA」のWebサイトです。

## 特徴
- **世界観とコンセプト**: 「光をまとう美しさ」「あなた本来の輝きを引き出す」「迷いから決断へ」の想いを余すことなく反映したエレガント＆信頼感あふれるデザイン
- **スマホ特化型UI**: 下部固定の「LINE相談 / WEB予約」ボタン、タップしやすいメニューなど、予約率を高める導線設計
- **レスポンシブデザイン**: PC / タブレット / スマートフォンすべてで美しく閲覧可能
- **構成**:
  - メインビジュアル（キャッチコピー・初回限定バッジ）
  - サロンの想い・ストーリー（Concept）
  - 選ばれる3つのこだわり（Commitment）
  - メニュー・料金一覧（カテゴリ切り替え機能付き）
  - お客様の声（Voice）
  - オーナー・セラピスト紹介（Profile）
  - 施術の流れ（Flow）
  - よくあるご質問（FAQアコーディオン）
  - サロン情報・アクセス（Access）
  - 24時間WEB予約モーダル & 公式LINE導線

## 起動方法（ローカル環境）

現在、ローカルサーバーが起動しています：
- **プレビューURL**: [http://localhost:3000/](http://localhost:3000/)

### サーバーの停止・再起動
```bash
# 開発サーバー起動
npm run dev

# 本番用静的ファイル書き出し（dist/に出力されます）
npm run build

# ビルドした本番プレビュー
npm run preview
```
